# ✂️ Barbearia Estilo

Sistema moderno e responsivo para agendamento online de serviços de barbearia, como corte masculino, barba estilizada e limpeza de pele. Projeto desenvolvido com HTML, CSS e JavaScript com integração direta com WhatsApp.

---

## 🚀 Funcionalidades

- Modal de agendamento com formulário
- Troca automática de imagens (slideshow)
- Integração com WhatsApp (abre conversa com dados preenchidos)
- Feedback visual com mensagem de agendamento concluído
- Layout responsivo para desktop e mobile
- Ícones de redes sociais no rodapé (Instagram e WhatsApp)

---

## 🧪 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome (para ícones)

---

## 🖼️ Layout

O site conta com:
- Imagem de fundo com sobreposição escura (`.overlay`)
- Seções de serviços organizadas com imagens e descrição
- Modal customizado com campos de agendamento
- Footer com links sociais
